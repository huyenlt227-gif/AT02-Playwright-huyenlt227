5.1The Problem POM Solves

EN Imagine writing 30 tests that all click the Login button. Without a page object, the selector button:has-text("Login") is pasted into 30 places. When the developer changes the button, you fix 30 tests. With POM, the selector lives once, inside the page class — you fix one file.

VI Tưởng tượng viết 30 test cùng bấm nút Login. Không có page object, selector button:has-text("Login") bị dán vào 30 chỗ. Khi dev đổi nút, bạn sửa 30 test. Với POM, selector nằm duy nhất một chỗ, trong class của trang — bạn sửa một file.

i
Rule of thumb: tests speak business ("login with these credentials"), page objects speak browser ("fill #email, click button"). Keep the two vocabularies separate.

5.2BasePage: the Shared Toolkit

EN Every page object extends BasePage (pages/common/BasePage.ts), which centralizes what every page needs: navigation, popup handling, and safe helpers.

VI Mọi page object đều kế thừa BasePage (pages/common/BasePage.ts) — nơi gom các thứ mọi trang đều cần: điều hướng, xử lý popup, và các helper an toàn.

TypeScript 
export abstract class BasePage {
  constructor(protected readonly page: Page) {}

  protected async goto(url: string): Promise<void> {
    await this.page.goto(url, { waitUntil: 'domcontentloaded' });
  }

  async closeAnnoyingPopups(): Promise<void> { /* demo popup + cookie */ }

  protected async getText(locator: Locator): Promise<string> {
    await locator.waitFor({ state: 'visible' });
    return ((await locator.textContent()) ?? '').trim();
  }

  protected async expectVisible(locator: Locator, description: string): Promise<void> {
    await expect(locator, description).toBeVisible();
  }

  protected async click(locator: Locator): Promise<void> {
    await locator.waitFor({ state: 'visible' });
    await locator.click();
  }

  protected async fill(locator: Locator, value: string): Promise<void> {
    await locator.waitFor({ state: 'visible' });
    await locator.fill(value);
  }
}

EN Note the protected keyword: helpers are visible to subclasses but not to tests. Tests only ever see public business methods.

VI Chú ý từ khóa protected: helper chỉ dùng trong class con, không lộ ra test. Test chỉ thấy method nghiệp vụ public.

5.3A Concrete Page Object: LoginPage

EN pages/user/LoginPage.ts owns the login screen: its locators (private) and its business actions (public).

VI pages/user/LoginPage.ts sở hữu màn hình login: locator (private) và hành động nghiệp vụ (public).

TypeScript 
export class LoginPage extends BasePage {
  private readonly emailInput = this.page.locator('#email');
  private readonly loginButton = this.page.locator('button:has-text("Login")');
  private readonly dashboardTitle = this.page.locator('h1:has-text("Dashboard")');

  async open(): Promise<void> {
    await this.goto(`${Env.USER_BASE_URL}/users/login`);
    await this.closeAnnoyingPopups();
    await this.expectVisible(this.loginTitle, 'Customer login page is not displayed');
  }

  async loginSuccess(email: string, password: string): Promise<void> {
    await this.login(email, password);
    await this.expectVisible(this.dashboardTitle, 'Dashboard page is NOT displayed after login');
  }

  async loginExpectFailure(email: string, password: string): Promise<string> {
    await this.login(email, password);
    await this.waitForVisible(this.errorNotification);
    return this.getErrorMessage();
  }
}

Read the test again (TC-03): the test never mentions #email or button. It calls loginPage.loginExpectFailure(...) — pure business language. That is the payoff of POM.

5.4Handling Real-World Messiness

EN Real sites are messy. Notice how LoginPage.login() defends against the demo popup swallowing the click — this kind of resilience lives in the page object, invisible to tests:

VI Website thật thì bừa bộn. Chú ý cách LoginPage.login() phòng thủ khi popup demo nuốt mất cú click — loại "chống chịu" này nằm trong page object, test không thấy:

TypeScript 
async login(email: string, password: string): Promise<void> {
  await this.fill(this.emailInput, email);
  await this.fill(this.passwordInput, password);
  await this.click(this.loginButton);

  // Safety net: if a popup reappeared and swallowed the click,
  // close it and retry the click once.
  await this.page.waitForTimeout(800);
  if (await this.page.locator('.website-popup').isVisible().catch(() => false)) {
    await this.closeAnnoyingPopups();
    await this.click(this.loginButton);
  }
}
