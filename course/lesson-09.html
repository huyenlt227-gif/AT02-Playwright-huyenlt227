9.2Workers & fullyParallel

EN workers controls how many browser instances run at once (from WORKERS, default 2; forced to 1 on CI). fullyParallel: true lets tests inside one file run in parallel too:

VI workers quyết định có bao nhiêu instance trình duyệt chạy cùng lúc (từ WORKERS, mặc định 2; ép về 1 trên CI). fullyParallel: true cho phép các test trong cùng file chạy song song:

TypeScript 
export default defineConfig({
  fullyParallel: true,
  workers: process.env.CI ? 1 : Number(process.env.WORKERS ?? 2),
  // ...
});
i
Speed vs. safety: parallel is faster, but parallel tests share the machine's CPU and the site's data. The framework trades speed for safety exactly where the data demands it — see next.

9.3Serial Mode: When Parallel Is Dangerous

EN Cart, checkout and e2e tests mutate the same customer account (add to cart, place orders). If two such tests ran in parallel, they would overwrite each other's state. Those files opt into serial mode:

VI Test cart, checkout và e2e thay đổi dữ liệu của cùng một tài khoản (thêm giỏ hàng, đặt đơn). Nếu hai test như vậy chạy song song, chúng sẽ ghi đè trạng thái của nhau. Các file đó chọn serial mode:

TypeScript 
// tests/user/cart/add-two-products.spec.ts
test.describe('Add Two Products to Cart', () => {
  test.describe.configure({ mode: 'serial' });
  // ... tests run one after another, in order
});

EN And the demo script runs the whole chromium suite with a single worker:

VI Và script demo chạy toàn bộ suite chromium với một worker duy nhất:

bash 
npm run test:demo   # playwright test --project=chromium --workers=1

9.4Why Firefox/WebKit Only Run Stateless Tests

EN Cross-browser support is demonstrated by the stateless tests (product info, profile) — they read data and revert their changes, so three browsers can run them in parallel safely. The stateful tests (cart, checkout, e2e) stay on chromium only; running them on three browsers simultaneously would make the browsers fight over the same cart and orders.

VI Hỗ trợ cross-browser được minh họa bằng các test stateless (thông tin sản phẩm, hồ sơ) — chúng đọc dữ liệu và hoàn tác thay đổi, nên ba trình duyệt chạy song song an toàn. Các test stateful (cart, checkout, e2e) chỉ chạy trên chromium; chạy trên ba trình duyệt cùng lúc sẽ khiến chúng tranh nhau giỏ hàng và đơn hàng.

!
Shared-account reality: this is a real constraint of testing a shared demo account, not a framework limitation. In a real project each test would get its own isolated user.

9.5Run Them All

bash 
npm run test:all-browsers   # chromium + firefox + webkit
npm run test:demo           # chromium, serial, 1 worker

EN After a cross-browser run, check output/products/ — you should see product-details.json, product-details-firefox.json and product-details-webkit.json.

VI Sau lần chạy cross-browser, kiểm tra output/products/ — bạn sẽ thấy product-details.json, product-details-firefox.json và product-details-webkit.json.

Exercise · Bài tập
  1. Chạy npm run test:all-browsers và ghi lại tổng số test trên mỗi trình duyệt.
  2. Quan sát các file output trong output/products/ — giải thích hậu tố tên file.
  3. Mở checkout.spec.ts — tìm dòng test.describe.configure({ mode: 'serial' }) và giải thích vì sao nó ở đó.
  4. Chạy npm run test:demo — so sánh thời gian với lần chạy song song.
