4.1What Is a Locator?

EN A locator is how you tell the robot which element to touch. It is like a GPS coordinate for an element on the page. Look at the locators in pages/user/LoginPage.ts:

VI Locator là cách bạn chỉ cho robot biết chạm vào phần tử nào. Nó giống tọa độ GPS cho một phần tử trên trang. Nhìn các locator trong pages/user/LoginPage.ts:

TypeScript 
private readonly emailInput = this.page.locator('#email');
private readonly passwordInput = this.page.locator('#password');
private readonly loginButton = this.page.locator('button:has-text("Login")');
private readonly errorNotification = this.page.locator('[data-notify="message"]');
private readonly loginTitle = this.page.locator('h1:has-text("Login to your account")');
SelectorMeaning · Ý nghĩa
#emailElement có id="email" — ổn định nhất
button:has-text("Login")Nút <button> có chữ "Login" — theo ý nghĩa nghiệp vụ
[data-notify="message"]Element có attribute data-notify — theo attribute ổn định
h1:has-text("...")Heading chứa text — dùng để xác nhận "đang ở đúng trang"
!
Bad locator habits: avoid positional selectors like div:nth-child(3) > span and brittle text like text=Welcome back John (breaks when the name changes). Prefer id, stable attributes, and business-meaningful text.

4.2Auto-Waiting: Why We Never Sleep

EN Manual testers instinctively pause ("wait for the page to load"). Playwright does this automatically: before every action it waits for the element to be visible, enabled and stable, up to a timeout. Random sleep() calls are slower and flakier — they wait even when nothing needs waiting.

VI Manual Tester có thói quen dừng lại chờ ("đợi trang load"). Playwright làm việc đó tự động: trước mỗi thao tác nó chờ phần tử hiển thị, bật và ổn định, tối đa theo timeout. Gọi sleep() lung tung vừa chậm vừa dễ flaky — nó chờ cả khi không cần chờ.

TypeScript 
// ❌ Manual-Tester instinct — slow and flaky
await page.waitForTimeout(5000);
await page.click('#login-button');

// ✅ Playwright way — waits only as long as needed
await page.locator('#login-button').click();

4.3Assertions Are Your Expected Results

EN An assertion is your expected result written in code. Playwright's expect also auto-waits, so it retries until the condition holds or the timeout expires. Common ones used in this project:

VI Assertion chính là expected result viết bằng code. expect của Playwright cũng auto-wait — nó thử lại cho đến khi điều kiện đúng hoặc hết timeout. Các loại thường dùng trong dự án:

TypeScript 
// Element is visible (auto-waits)
await expect(locator, 'Dashboard page is NOT displayed after login').toBeVisible();

// Text contains a substring (e.g. error message)
expect(message).toContain('Invalid login credentials');

// Element text equals exactly
await expect(this.productTitle).toHaveText('test');

// Boolean condition is true
expect(await loginPage.isOnLoginPage()).toBe(true);
AssertionChecks · Kiểm tra
toBeVisible()Phần tử hiển thị trên màn hình
toContainText(...) / toContain(...)Text chứa chuỗi con
toHaveText(...)Text bằng chính xác giá trị
toBeTruthy() / toBe(true)Giá trị boolean / truthy
toBeGreaterThan(...)Số lớn hơn ngưỡng (ví dụ độ dài mã đơn hàng)
i
Second argument = failure message. expect(locator, 'Dashboard page is NOT displayed after login') — when the assertion fails, your message appears in the report, so you instantly know what broke without reading the trace.

4.4Robust Patterns in This Project

EN The framework centralizes fragile interactions in pages/common/BasePage.ts. Notice how helpers wait for visibility before acting, and how popups that would intercept clicks are dismissed:

VI Framework gom các thao tác dễ vỡ vào pages/common/BasePage.ts. Chú ý cách các helper chờ hiển thị trước khi thao tác, và cách popup chặn click bị đóng đi:

TypeScript 
protected async click(locator: Locator): Promise<void> {
  await locator.waitFor({ state: 'visible' });
  await locator.click();
}

protected async fill(locator: Locator, value: string): Promise<void> {
  await locator.waitFor({ state: 'visible' });
  await locator.fill(value);
}

async closeAnnoyingPopups(): Promise<void> {
  // closes the demo popup + cookie banner that would swallow clicks
}
