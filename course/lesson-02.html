Setup & Project Structure

Cài đặt & Cấu trúc dự án

Preconditions · Tiền đề
  • Hoàn thành TC-01
  • Máy có Node.js 18+ và npm
Expected Result · Sau bài này bạn làm được
  • Cài dependencies và trình duyệt Playwright
  • Giải thích ý nghĩa từng thư mục trong repo
  • Điền đúng .env từ .env.example
  • Đọc được các script trong package.json

2.1Install the Dependencies

EN Open a terminal in the project root and run:

VI Mở terminal tại thư mục gốc của dự án và chạy:

bash 
npm install
npx playwright install

EN The first command installs Playwright, TypeScript and the helpers. The second downloads the browser binaries (Chromium, Firefox, WebKit) that the tests drive. This happens once.

VI Lệnh đầu cài Playwright, TypeScript và các thư viện hỗ trợ. Lệnh thứ hai tải trình duyệt (Chromium, Firefox, WebKit) mà test sẽ điều khiển. Chỉ cần chạy một lần.

2.2Configure .env

EN Secrets and URLs never live inside test code. Copy the example file and fill in real values:

VI Mật khẩu và URL không bao giờ nằm trong code test. Copy file mẫu và điền giá trị thật:

bash 
cp .env.example .env
VariableMeaning · Ý nghĩa
USER_BASE_URLStorefront URL (phía khách hàng)
ADMIN_BASE_URLAdmin login URL
CUSTOMER_EMAIL / CUSTOMER_PASSWORDTài khoản khách dùng cho test cần đăng nhập
ADMIN_EMAIL / ADMIN_PASSWORDTài khoản admin dùng cho test admin
DEFAULT_TIMEOUTGlobal timeout (ms), mặc định 30000
WORKERSSố worker chạy song song, mặc định 2
✕
Never commit .env or storage/. Both are already git-ignored. The demo accounts (customer@example.com / 123456) may stop working when the demo site resets — see TC-11.

2.3Walk the Folder Tree

EN The structure follows a clear convention — every folder has one job:

VI Cấu trúc tuân theo một quy ước rõ ràng — mỗi thư mục có đúng một nhiệm vụ:

Folder · Thư mụcJob · Nhiệm vụ
pages/Page Object Model — mỗi màn hình là một class (TC-05)
fixtures/Fixture — cấp sẵn page object cho từng test (TC-06)
tests/File test theo module: user/, admin/, e2e/
data/Test data dạng JSON, tách khỏi code (TC-08)
utils/Tiện ích: đọc env, JSON, Excel, logger, so sánh dữ liệu
setup/Đăng nhập một lần, lưu session (TC-07)
storage/Session đã lưu (git-ignored)
output/Dữ liệu sản phẩm capture được (git-ignored)
logs/, test-results/, playwright-report/Log, screenshot/video/trace, HTML report (TC-10)

2.4The npm Scripts

EN package.json defines ready-made commands. You almost never need to type the raw playwright test command:

VI package.json định nghĩa sẵn các lệnh. Bạn gần như không cần gõ lệnh playwright test thô:

Command · LệnhRuns · Chạy gì
npm testToàn bộ suite (setup + tất cả project)
npm run test:loginChỉ module login
npm run test:profile / test:product / test:cart / test:checkout / test:admin / test:e2eTừng module riêng lẻ
npm run test:all-browsersChromium + Firefox + WebKit
npm run test:demoChromium, 1 worker, chạy tuần tự
npm run reportMở HTML report
npm run typecheckKiểm tra kiểu TypeScript (tsc --noEmit)
i
Sanity check: run npm run typecheck now. Zero errors means your environment is ready.
Exercise · Bài tập
  1. Chạy npm install và npx playwright install (nếu chưa).
  2. Copy .env.example thành .env và điền thông tin tài khoản.
  3. Chạy npm run typecheck — xác nhận 0 lỗi.
  4. Mở package.json, chọn 3 script và đoán xem mỗi script chạy project nào trong playwright.config.ts.
Test Report · Báo cáo kiểm thử

EN Your machine is ready and you can navigate the project. Next: write and run your first test.

VI Máy đã sẵn sàng và bạn điều hướng được dự án. Bài tiếp theo: viết và chạy test đầu tiên.
