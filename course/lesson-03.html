3.1The Anatomy of a Spec File

EN Open tests/user/login/login.spec.ts. A Playwright test file is a series of test cases — exactly like the test cases you write in Excel or TestRail, but in code:

VI Mở tests/user/login/login.spec.ts. Một file test Playwright là chuỗi các test case — giống hệt test case bạn viết trong Excel hay TestRail, nhưng bằng code:

TypeScript 
import { test, expect } from '../../../fixtures/base.fixture';
import { Env } from '../../../utils/env';
import { JsonHelper } from '../../../utils/json-helper';

const loginData = JsonHelper.readData<{
  invalidEmail: string;
  invalidPassword: string;
  expectedInvalidCredentialsMessage: string;
}>('login/login-data.json');

test.describe('Customer Login', () => {
  test('Login with an invalid email shows an error message', async ({ loginPage, log }) => {
    await test.step('Open the customer login page', async () => {
      await loginPage.open();
    });

    await test.step('Submit the form with an invalid email', async () => {
      const message = await loginPage.loginExpectFailure(
        loginData.invalidEmail,
        Env.CUSTOMER_PASSWORD,
      );
      log.info(`Error message received: "${message}"`);
      expect(message).toContain(loginData.expectedInvalidCredentialsMessage);
    });
  });
});
KeywordRole · Vai trò
test.describe('...')Nhóm các test case (giống test suite / folder)
test('...', async ({ ... }) => {})Một test case. Title là tên hiển thị trong report
test.step('...', async () => {})Chia test case thành các bước nghiệp vụ — report hiển thị từng bước
expect(...).toContain(...)Assertion: kiểm tra kết quả thực tế với expected
{ loginPage, log }Fixture: Playwright tự tạo sẵn page object và logger cho bạn (TC-06)

3.2Read a Test Like a Manual Tester

EN Compare the first test case with a manual test case you would write:

VI So sánh test case đầu tiên với test case thủ công bạn thường viết:

Manual test casePlaywright equivalent · Tương đương trong Playwright
Precondition: mở trang loginloginPage.open()
Steps: nhập email sai, nhập password, bấm LoginloginPage.loginExpectFailure(email, password)
Expected: hiện thông báo "Invalid login credentials"expect(message).toContain('Invalid login credentials')
Actual: ghi vào test reportlog.info(...) → ghi vào file log
i
Key insight: a good automation test is a manual test case translated line by line. Your manual-testing habit of writing clear steps is exactly what makes good automation tests.

3.3Run It

EN Run only the login module:

VI Chạy riêng module login:

bash 
npm run test:login

EN Watch the terminal: Playwright prints each test with a green ✓ (passed) or red ✘ (failed), plus the duration. The login project runs without a saved session, so it performs a real login against the demo site.

VI Quan sát terminal: Playwright in từng test với ✓ xanh (passed) hoặc ✘ đỏ (failed) kèm thời gian. Project login chạy không dùng session đã lưu, nên nó thực hiện đăng nhập thật trên site demo.

3.4Read the HTML Report

EN After the run, open the interactive report:

VI Sau khi chạy, mở report tương tác:

bash 
npm run report

EN The report shows every test case, its steps, duration, and — on failure — the error, screenshot, video and trace. This is your "test execution log" in a familiar format.

VI Report hiển thị mọi test case, từng bước, thời gian, và — khi fail — lỗi, screenshot, video và trace. Đây chính là "nhật ký thực thi" của bạn dưới dạng quen thuộc.

Exercise · Bài tập
  1. Chạy npm run test:login và ghi lại số test passed / failed.
  2. Mở HTML report, click vào test "Login with an invalid email…", xem danh sách các step.
  3. Trong login.spec.ts, thêm test case thứ 4: login với email trống (empty). Gợi ý: tái sử dụng loginExpectFailure với ''.
  4. Chạy lại và xác nhận test mới hiển thị trong report.
