12.1The Capstone: Build a "Product Search" Module

EN Build a new module from scratch, following the framework's own conventions. Goal: a test that opens the storefront, searches for a product by name, and asserts the result list shows the expected product.

VI Tự xây một module mới từ đầu, theo đúng quy ước của framework. Mục tiêu: một test mở storefront, tìm kiếm sản phẩm theo tên, và assert danh sách kết quả hiển thị đúng sản phẩm.

Step 1 · Explore the page

EN Open the storefront manually, use DevTools to find the search input and the result container. Write down the stable selectors — this is your locator research.

VI Mở storefront bằng tay, dùng DevTools tìm ô tìm kiếm và vùng kết quả. Ghi lại selector ổn định — đây là bước nghiên cứu locator của bạn.

Step 2 · Create the page object

EN Create pages/user/SearchPage.ts extending BasePage, with a search(keyword) method and an assertion helper. Remember: goto() then closeAnnoyingPopups().

VI Tạo pages/user/SearchPage.ts kế thừa BasePage, với method search(keyword) và helper assert. Nhớ: goto() rồi closeAnnoyingPopups().

Step 3 · Register the fixture

EN Add searchPage to fixtures/base.fixture.ts so tests receive it out of the box.

VI Thêm searchPage vào fixtures/base.fixture.ts để test nhận sẵn page object.

Step 4 · Put the keyword in data

EN Create data/search/search-data.json with the keyword, and read it via JsonHelper.readData<T>().

VI Tạo data/search/search-data.json chứa từ khóa, đọc qua JsonHelper.readData<T>().

Step 5 · Write the test

EN Create tests/user/search/search.spec.ts with test.step blocks, a meaningful assertion message, and log.info calls.

VI Tạo tests/user/search/search.spec.ts với các khối test.step, assertion message có nghĩa, và các lệnh log.info.

Step 6 · Run, verify, evidence

EN Run it. If it fails, debug with the TC-11 method. Confirm the report, log and (on failure) artifacts are produced.

VI Chạy nó. Nếu fail, debug theo phương pháp TC-11. Xác nhận report, log và (khi fail) các artifact được sinh ra.
